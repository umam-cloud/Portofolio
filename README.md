# Personal Portfolio Website

Personal portfolio website with an admin dashboard to manage projects.  
Designed with a modern dark theme and built using native PHP and MySQL.

🌐 Live Demo: https://fatihulumam.gt.tc

## ✨ Features

### Public
- Responsive landing page
- Modern dark mode UI
- Project listing
- Project detail page

### Admin Panel
- Admin authentication (login)
- Dashboard overview
- Add, edit, and delete projects
- Upload project images
- Manage tech stack and descriptions

---

## 🛠 Tech Stack

- HTML5  
- CSS3  
- JavaScript  
- PHP (Native)  
- MySQL  

---

## 📂 Project Structure

```

/admin          → admin dashboard & authentication
/assets         → css, js, images
/uploads        → uploaded project images
/config         → database configuration
/index.php      → landing page

````

---

## ⚙️ Installation & Setup

1. Clone this repository
```bash
https://github.com/umam-cloud/Portofolio.git
````

2. Move the project to your local server directory
   (e.g. `htdocs` for XAMPP)

3. Import database

* Open phpMyAdmin
* Import the provided `.sql` file

4. Configure database connection

* Edit file inside `/config/`
* Adjust database name, username, and password

5. Run the project in your browser

```
http://localhost/project-name
```
